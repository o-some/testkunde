# Bodyweight Club

Calisthenics-Präsentation in Deutsch, Englisch und Türkisch. Angebot: 50 € pro Person und Monat, drei wöchentliche Termine, maximal zehn Personen pro Einheit.

## Funktionen
Drei begrenzte Parallax-Momente, native Scrollsteuerung, reduzierte Bewegung, pausierbare Trainingsgedanken, sechs Bildanleitungen mit Schritt-Auswahl, Glossar und lokale Trainingsnotizen. Der Einstiegsplaner verarbeitet Auswahlwerte ausschließlich im Browser und reserviert keinen Platz.

## Betrieb
GitHub Pages im Repository o-some/testkunde. Neue UI-Assets: style-sale12.css und app-sale12.js. Keine externen Runtime-Abhängigkeiten, kein Tracking, keine Zahlungsabwicklung und keine Übermittlung der Planungsauswahl. Bildquellen sind auf bildnachweise.html aufgeführt.

## Erforderliche Betreiberkonfiguration
Verantwortlichen Diensteanbieter und Kontaktdaten in Impressum und Datenschutz ergänzen. Echten Anmeldeweg und Teilnahmebedingungen bereitstellen. Die Website enthält dafür keine erfundenen Anbieterangaben.
